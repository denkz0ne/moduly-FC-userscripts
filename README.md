# moduly-FC-userscripts

## Contributing userscripts

- Before changing a userscript, create a new GitHub Issue for that change. Use one issue per affected userscript.
- Link the issue from the pull request and close it when the change is merged.
- Preserve existing Tampermonkey identity and update metadata unless the issue explicitly tracks a migration. If an update path changes, include the manual reinstall URL in the issue and pull request.
- Keep unrelated projects and folders out of userscript changes.
